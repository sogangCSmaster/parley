# Gemini real-time caption pipeline measurements (2026-10-16)

Tool: [bench/gemini](../../bench/gemini). Environment: Seoul, Gemini API **free tier** key, macOS TTS audio (Yuna, Kyoko).

## Summary

| Item | Result | Verdict |
|---|---|---|
| STT first interim result | ko 0.73s · ja 1.16s after audio starts | Good |
| STT interim cadence | **~0.49s** (p90 0.53s) | Good — captions keep up with speech |
| STT lag (speech → interim) | ~0.5–0.7s | Good |
| STT end of speech → final | ko 1.34s · ja 0.12s | Good |
| Translation (Flash-Lite) first token | **p50 2.49s · p90 3.84s · max 10.4s** | **Over target (1.5s)** |
| Translation output speed | total − first token ≈ 0.1s | Fast once it starts |
| Thinking tokens | 0 (`thinkingLevel: minimal`) | Thinking off works |
| Free-tier errors | 4 of 38 calls failed (503 overloaded, 429 quota) | Not usable for a real service |
| Network round-trip | Connect 40ms, TLS 85ms | **Network isn't the bottleneck** |
| Translation cost | ~97 input tokens, ~19 output tokens per call → **$0.000076/call** | Very cheap (projected $0.003/min at 40 calls/min) |

## Conclusion

- **STT (`gemini-3.5-transcribe-live`) fits the requirements as-is.** It sends the full text so far every 0.5s, so "captions that follow while you speak" works right away.
- **Translation latency is the only blocker.**
  - Network is ~40ms and output is ~0.1s, so almost all of the ~2.4s is model wait time on the free tier.
  - The paid tier (and its Priority tier) still needs to be measured, which means enabling billing.
- Real cost per speaking minute ≈ STT $0.009 + translation $0.003 ≈ **$0.012/min**. That's half of the earlier $0.025 estimate.

## Facts that affect the design

1. **Interim results are cumulative within a segment, and reset when a final arrives.** A final is cut at a pause, not at a sentence end; one Japanese final ended mid-sentence at "主にAI".
   → For each speaker, keep "final segments not yet ending a sentence + the current interim" stitched into one sentence buffer, and translate that buffer. Lock a sentence's translation only once the sentence-ending punctuation (。.?!) arrives.
2. **Japanese interims have spaces between words** ("私たち の 投資"); finals have none. → Remove spaces between CJK characters before displaying or translating.
3. An interim often comes back with no change from the previous one. → Only translate when the text has changed.
4. Recognition error example: TTS audio "注力しています" was recognized as "よく知っています". → Test with real voices, and consider adding meeting-specific terms with `customVocabulary`.
5. `gemini-2.5-flash-lite` can no longer be used by new users (404). `gemini-3.6-flash` was hard to measure on the free tier (9 successes, p50 1.4s).

## Next measurements

- Rerun with billing enabled, on the paid tier (and Priority tier). This decides whether translation fits within the 1.5s target.
- If it still doesn't fit: try keeping a persistent per-speaker connection with the Live API (text in/out) to cut per-request overhead.
